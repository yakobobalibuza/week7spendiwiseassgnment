
# SpendWise – Personal Finance Tracker

## Project Description

SpendWise is a responsive personal finance management
application designed to help users monitor their income,
expenses, savings and daily financial activities.

The application allows users to record transactions,
categorize spending, view their financial balance and
visualize income and expenses.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- Git and GitHub
- Netlify
- Browser Local Storage

## Deployment Process Summary

1. Organized the project files into a structured folder.
2. Created a public GitHub repository.
3. Uploaded the project files to GitHub.
4. Connected the GitHub repository to Netlify.
5. Configured Netlify to publish the project.
6. Customized the Netlify site name.
7. Tested the live website.
8. Updated the project and pushed changes to GitHub.
9. Verified that Netlify automatically deployed the latest changes.

## Challenges Encountered During Deployment

- Organizing the project files correctly.
- Connecting GitHub to Netlify.
- Ensuring that CSS and JavaScript files loaded correctly.
- Testing the website across different screen sizes.
- Verifying automatic deployment after updating the repository.
